# Documentation Update Rule

After completing any implementation phase or making significant code changes to the HITRAG project, **always** update [`docs/system_architecture.md`](file:///Users/tinochan06/hitrag/docs/system_architecture.md) with:

1. A new numbered section documenting the key architectural decisions made in that phase.
2. Updated entries in the **Verification & Testing** section for any new test files or scripts added.

This ensures the documentation stays in sync with the codebase at all times.
